# HormoCycleAI

An interactive menstrual and reproductive health research-monitoring dashboard.

## Features
1. Hormonal Pattern Prediction
2. Cycle Forecast
3. ARHI with score explanation
4. Explanation of contributing factors
5. Personalized Recommendations

## Run locally
Install dependencies with `pip install -r requirements.txt`, then run `streamlit run app/app.py`.

Outputs are for educational and research-monitoring purposes and are not medical diagnoses.
